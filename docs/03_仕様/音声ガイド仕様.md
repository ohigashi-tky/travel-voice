# 音声ガイド仕様書

## 概要

本仕様書は、「おうち旅行」アプリケーションにおける音声ガイド機能の拡張仕様を定義します。
現在の1分程度の短い音声ガイドから、3〜5分の充実した内容へと拡張し、訪問者により深い体験を提供することを目的とします。

## 現状分析

### 現在の実装
- **所要時間**: 約1分
- **使用テーブル**: `travel_spots`、`guides`
- **構成要素**: 
  - 基本的な挨拶
  - 簡単な説明（description）
  - 見どころ（highlights）
  - 締めの挨拶

### 課題
- 内容が表面的で深みがない
- 歴史的背景や文化的意義の説明が不足
- 聞き手を引き込むストーリー性の欠如
- 季節や時間帯による変化の情報がない

## 新仕様

### 1. データベース設計

#### 1.1 テーブル拡張案

**Option A: travel_spotsテーブルの拡張**
```sql
ALTER TABLE travel_spots ADD COLUMN extended_guide_content JSON;
ALTER TABLE travel_spots ADD COLUMN guide_duration_minutes INTEGER DEFAULT 3;
```

**Option B: guidesテーブルの拡張（推奨）**
```sql
ALTER TABLE guides ADD COLUMN extended_content JSON;
ALTER TABLE guides ADD COLUMN voice_tone VARCHAR(50) DEFAULT 'formal';
ALTER TABLE guides ADD COLUMN target_audience VARCHAR(50) DEFAULT 'general';
ALTER TABLE guides ADD COLUMN season_specific_content JSON;
```

### 2. 音声ガイドの構成

#### 2.1 時間配分（5分版）

| セクション | 所要時間 | 内容 |
|-----------|---------|------|
| イントロダクション | 30秒 | 温かい歓迎と雰囲気の描写 |
| 歴史と背景 | 90秒 | 創建の経緯、重要な出来事、人物 |
| 建築・芸術 | 60秒 | 様式、特徴、技術的驚き |
| 文化的意義 | 60秒 | 社会的役割、現代への影響 |
| 季節の魅力 | 45秒 | 四季それぞれの見どころ |
| 豆知識・秘話 | 45秒 | 知られざるエピソード |
| 訪問のヒント | 30秒 | 実用的なアドバイス |
| クロージング | 20秒 | 印象的な締めくくり |
| **合計** | **5分20秒** | バッファ込み |

#### 2.2 時間配分（3分版）

| セクション | 所要時間 | 内容 |
|-----------|---------|------|
| イントロダクション | 20秒 | 簡潔な歓迎 |
| 歴史と背景 | 60秒 | 主要な歴史のみ |
| 建築・文化 | 45秒 | 統合して説明 |
| 季節の魅力 | 30秒 | 現在の季節に特化 |
| 豆知識 | 20秒 | 1-2個の興味深い事実 |
| クロージング | 15秒 | 簡潔な締め |
| **合計** | **3分10秒** | バッファ込み |

### 3. ストーリーテリング手法

#### 3.1 導入部の工夫
```
例：「東京スカイツリーの展望台へようこそ。
今、あなたが立っている場所から634メートル下では、
江戸時代には職人たちが暮らす下町が広がっていました。
時代は変わり、この場所から見える景色も大きく変わりましたが、
富士山への眺望だけは、今も昔も変わらず人々を魅了し続けています。」
```

#### 3.2 感覚的描写の活用
- **視覚**: 「目の前に広がる朱塗りの鳥居が...」
- **聴覚**: 「風鈴の音が静かに響く回廊を...」
- **嗅覚**: 「線香の香りが漂う本堂では...」
- **触覚**: 「なめらかな石畳を歩きながら...」

#### 3.3 インタラクティブ要素
- 「ここで少し立ち止まって、天井を見上げてみてください」
- 「右手に見える石碑には...」
- 「もし時間があれば、裏手にある小さな庭園も...」

### 4. バリエーション展開

#### 4.1 対象別バリエーション

| タイプ | 所要時間 | 特徴 | 対象 |
|--------|---------|------|------|
| スタンダード版 | 3分 | 基本情報中心、バランス良く | 一般観光客 |
| ディープ版 | 5分 | 詳細な歴史と文化、専門的内容も | 歴史・文化愛好家 |
| ファミリー版 | 3分 | 物語調、クイズ要素、分かりやすい | 家族連れ |
| クイック版 | 2分 | 要点のみ、効率的 | 時間がない人 |
| アクセシブル版 | 4分 | ゆっくりした話速、詳しい説明 | 高齢者、障がい者 |

#### 4.2 季節別カスタマイズ
- 訪問時期に応じて、その季節の見どころを強調
- 特別なイベントがある場合は、その情報を追加
- 季節の変化による景観の違いを説明

### 5. 音声合成の工夫

#### 5.1 音声パラメータ
```json
{
  "voice_settings": {
    "speed": 0.95,  // 少しゆっくり
    "pitch": 0,     // 標準
    "volume": 0,    // 標準
    "emphasis": {
      "important_words": "strong",
      "numbers": "moderate",
      "place_names": "clear"
    }
  }
}
```

#### 5.2 間（ポーズ）の活用
- 重要な情報の後: 1.5秒
- 段落の切り替わり: 1.0秒
- 文の区切り: 0.5秒
- 感動的な場面の後: 2.0秒

### 6. 品質管理

#### 6.1 コンテンツレビュー基準
- [ ] 事実の正確性
- [ ] 文章の流れと自然さ
- [ ] 時間配分の適切さ
- [ ] 聞き手を引き込む要素の有無
- [ ] 地域性や文化的配慮

#### 6.2 音声品質チェック
- [ ] 発音の正確性（特に固有名詞）
- [ ] 音声の明瞭性
- [ ] 適切な速度とリズム
- [ ] 感情表現の適切さ

## まとめ

本仕様により、単なる情報提供から「体験」としての音声ガイドへと進化させ、
訪問者により深い感動と理解を提供することを目指します。
